# zizi-website-reference.md

بانتظار الأصل.

لم يكن ملف `zizi-website-reference.md` أو مجلد `C:\ziziwebsite\zizi-planning` متاحا داخل مساحة العمل عند تجهيز المشروع. عند إضافة الملف الأصلي، يجب استبدال هذا المحتوى بنسخة المرجع كما هي، ثم مراجعة أي بيانات عروض على أساس قراراته الأخيرة.

قواعد مؤقتة إلى حين وصول الأصل:

- لا تخترع أسعارا أو توفرات أو أوصافا أو مؤهلات.
- لا تعدل محتوى العروض دون الرجوع إلى المرجع الأصلي.
- ما لم يصل من الصور أو البيانات يسجل "بانتظار الأصل".
